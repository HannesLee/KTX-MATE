# KTX MATE

필요한 날짜를 말하면 예매 오픈일을 알려 주고, 오픈 시각에 맞춰 예매를 돕고, 달력에 티켓 현황을 표시해 주는 앱.
Expo(React Native)로 만들어서 맥 없이 개발하고, 같은 코드로 아이폰과 안드로이드를 모두 지원합니다.

## 지금 되는 것 (1단계)

- 월간 달력에 날짜별 예매 상태 표시: 오픈 대기(회색) / 예매 필요(주황) / 예매 완료(파랑) / 차선 필요(빨강)
- 일정 등록: 하루, 또는 이번 달·다음 달의 특정 요일 반복
- 말로 등록: "이번달 매주 월요일 7시 서울에서 부산", "12월 24일 저녁 6시반 부산에서 서울로", "다음주 금요일 오전 9시 대전 서울"
- 공공데이터포털 TAGO 시간표로 희망 시각에 가장 맞는 열차 추천 + 차선 3개
- 예매 오픈일 계산 (평상시: 승차일 1개월 전 07:00)
- 오픈 하루 전 / 10분 전 / 정각 알림, 알림에서 "코레일+ 열기"
- "코레일+에서 예매하기" 버튼: 열차 정보를 복사하고 코레일+ 앱으로 이동
- 예매 후 "예매 완료로 표시" (좌석은 선택 입력)
- 매진이면 "차선 열차 보기"로 같은 날 대안 열차로 교체
- 캘린더: 정식 빌드에서는 "KTX MATE" 캘린더에 자동 등록·갱신, Expo Go에서는 "아이폰 캘린더에 추가" 버튼(파일로 추가)

## 내 아이폰에서 실행하기 (맥 필요 없음)

준비물: 윈도우 PC, 아이폰(같은 와이파이)

1. 아이폰 App Store에서 **Expo Go** 설치
2. PC에 [Node.js LTS](https://nodejs.org/ko) 설치
3. PC에서 이 저장소 내려받기: GitHub 저장소 화면의 초록색 **Code → Download ZIP** 후 압축 풀기 (또는 `git clone`)
4. 압축 푼 폴더에서 터미널(PowerShell)을 열고:
   ```
   npm install
   npx expo start
   ```
5. 화면에 뜨는 QR코드를 아이폰 **카메라**로 찍으면 Expo Go에서 앱이 열립니다
6. 처음 열리면 설정 화면이 뜹니다. [공공데이터포털 TAGO 열차정보](https://www.data.go.kr/data/15098552/openapi.do)에서 "활용신청" 후 받은 **일반 인증키(Decoding)** 를 붙여넣으세요

같은 와이파이가 아니면 `npx expo start --tunnel` 로 실행하세요.

## 개발자용

```
npm test           # 핵심 로직 테스트 (오픈일, 반복, 추천, 시간표 파싱, 말로 등록, 캘린더 파일)
npm run typecheck  # 타입 검사
```

```
App.tsx            화면 전환(달력 + 등록/상세/설정 시트), 알림 응답 처리
src/core/          순수 로직: 시간(KST), 오픈 규칙, 반복 일정, 추천, TAGO 파싱, 말로 등록, .ics
src/services/      저장(AsyncStorage), 캘린더, 알림, 코레일+ 넘기기
src/screens/       달력 / 등록 / 상세 / 설정
src/store.tsx      일정 상태와 흐름(등록 → 추천 → 캘린더 → 알림)
__tests__/         로직 테스트
```

## 확인이 필요한 것

- 역 코드(`src/core/models.ts` 의 STATIONS)는 TAGO 역 목록 응답으로 한 번 검증
- 코레일+ 앱 URL 스킴(`src/services/handoff.ts`) 실제 값 확인. 안 열리면 웹으로 넘어감
- 오픈 규칙은 코레일 공지 기준으로 최종 확인, 명절 예외는 `overrides` 로
